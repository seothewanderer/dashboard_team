# 관계표(브리지) 검토 안내

- 생성: 2026-09-30, `scripts/draft_bridges.py` (plan.md P2, research 10.2)
- 모든 행은 `review_status = draft`로 만들어졌다. 앱은 `reviewed`만 확정 연결로 쓰고, `draft`는 '검토 전 후보' 배지로 보여 주며, `rejected`는 쓰지 않는다.
- 검토 방법: CSV를 엑셀로 열어 `review_status`를 `reviewed` 또는 `rejected`로 바꾸고, 필요하면 `review_note`에 이유를 적는다. 저장은 **CSV UTF-8** 형식으로 한다. 그다음 `.venv\Scripts\python.exe scripts\build_data.py`를 실행하면 앱에 반영된다(허용값이 아니거나 없는 ID를 참조하면 빌드가 멈추고 알려 준다).
- 초안 스크립트는 **이미 있는 파일을 덮어쓰지 않는다.** 규칙(아래 3·4)을 바꿔 다시 만들고 싶으면 행을 검토하기 전에 `--overwrite`로 재생성한다.

정확히 같은 글자(`match_method = identity`)는 검토 없이도 검색에 쓴다(plan 9.4의 7.1 '정확 용어'). 검토가 필요한 것은 서로 다른 표기를 같은 기술로 묶는 행이다.

## 수집 검색어 관계표 (`course_search_keywords.csv`, 2026-10-01 요청 J2-1)

- `scripts/make_course_keywords.py`가 고용24 수집 원본(../DataCollect/work24, 1차 드론 7개·2차 기술 15개 검색어)에서 과정 ID별 검색어를 옮긴 표. `build_data.py`가 이 표로 `courses.search_keywords`를 다시 채운다(전처리에서 '드론' 하나로 합쳐진 검색어 복원).
- 사람 판단이 없는 수집 기록 그대로라 모든 행을 `reviewed`로 둔다. 다시 만들려면 스크립트를 다시 실행한다(덮어씀).
