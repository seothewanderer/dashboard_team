## v7 수정본에서 달라진 것

- **04 기업 탐색:** '함께 하는 분야' 막대를 누르면 왼쪽 분야는 그대로, 기업 카드만 두 분야를 모두 하는 곳(교집합)으로. 다시 누르거나 카드 줄 '✕ 함께 하는 분야'로 해제.
- **03 준비 역량:** 채용 키워드 그래프 얇은 막대, '분류' 이름은 묶음 밖 위·묶음은 모서리 둥근 사각형(1920px에서 앱과 높이·줄 위치 같음).
- **01 산업 이해:** 활용 분야 히트맵 이름을 가로 한 줄로(글자 한 단계 작게).
- **02 직무 탐색:** '직무 키워드와 보유 기술로 필터링'에서 고른 키워드가 위 직무 카드를 거름(아래 카드 목록 없음).
- **목표 직무 관련 강조:** 03·채용 현황·기업 탐색 화면마다 따로, 들어올 때마다 꺼짐.
- **나의 탐색 경로:** 학습 내용·채용 공고·관심 기업 스크랩별 '초기화', 내 조건 '초기화'(회색 글자).
- **푸터:** 로고 크게, 보여들이조(굵고 크게) + 조원.

## v4 수정본에서 달라진 것

- 카드: 별(해당 직무 선택)·책갈피(스크랩) 단추, 선택·스크랩 카드 떠오름 + 초록 그림자, 드론 교육 초록 띠, 기본 카드 테두리.
- 02 직무 탐색
  - 3D 홀로그램 네트워크(앱과 같은 코드): 끌어서 회전, 마우스를 올리면 정지.
  - 오른쪽 열: 방산 관련 직무 ↔ 전체 보기, 대분류·중분류 한 줄씩, 관련 직무 카드 보러가기.
  - 검색 상자, 근거 유형 삭제, 직무 카드 펼치기 + 방산 관련만 보기.
- 03: 공고 기술 그래프는 '채용 키워드' 탭에서만, '드론 관련만 보기'.
- 04 채용 현황
  - KPI 아이콘 카드(방산 비율 빨강).
  - 공고 조건 한 줄(그래프·지도와 같은 선택), 방산 관련 기업만 보기.
  - 직무 막대 + 지역 지도 연동(앱과 같은 코드), 비율(%)로 보기.
  - 공고 카드 펼치기(목표 직무 강조 포함), 비교 안내 상자.
- 04 기업 탐색: 검색 상자, 기업 카드 펼치기 + 방산 관련만 보기.
- 나의 탐색 경로: '내 조건'(학력·경력·희망 지역) 입력. 방산 강조는 저장하지 않음.
- 검색 상자는 브라우저 기본 자동완성 목록(datalist)으로 동작: 입력하면 추천, 칸을 누르면 전체 목록(브라우저마다 모양이 조금 다름).
